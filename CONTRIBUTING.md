# Contributing

Votepit is solo-maintained. Contributions and feedback are welcome — please use
the right channel so things don't get lost:

- **Questions, self-hosting tips, general chat** → [Discussions ›
  General](https://github.com/silvio-l/Votepit/discussions/categories/general)
- **Feature ideas or feedback on Votepit itself** → vote or submit on our own
  [Votepit feedback board](https://app.votepit.com/silvio-und-maik/votepit-feedback) <!-- export-ok: * (our own public production app, meant to be linked) -->
  (yes, we dogfood our own product), or post in [Discussions ›
  Ideas](https://github.com/silvio-l/Votepit/discussions/categories/ideas) —
  whichever you prefer, both get their own upvote button.
- **Bug reports** → [open an
  issue](https://github.com/silvio-l/Votepit/issues/new/choose) using the bug
  report template.
- **Security vulnerabilities** → see [`SECURITY.md`](SECURITY.md), not a public
  issue.

## Pull requests

Small, focused fixes (typos, clear bugs, docs) are welcome directly as a PR.
For anything larger — new features, architectural changes — please open a
Discussion first, so we can agree on direction before you invest time.

Setup, coding standards, and the test suite are documented in
[`documentation/development.md`](documentation/development.md). Run
`composer qa` before opening a PR.

## Response time

This is a solo-maintained project. There's no SLA, but I try to get to issues,
discussions, and PRs within a few days.
